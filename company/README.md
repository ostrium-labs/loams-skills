# Company workspace

Everything in this directory is yours. The template ships examples; replace them
with your facts.

| Path | Fill it in |
|---|---|
| `company.yaml` | Company, cloud, IdP, Loams version, edge languages |
| `stack-inventory/` | Services, data, risks, costs |
| `architecture/` | Fit decisions and target topology |
| `decisions/` | Your ADRs, starting with D0001 |
| `sdk-matrix.md` | Which languages and packages you keep |
| `runbooks/` | Migration, cutover, operate, restore, upgrade |
| `adoption-status.md` | Current stage, evidence, blockers, next actions |

Start with `stack-inventory/inventory.md`. A fictional filled example is in
`stack-inventory/example-filled.md`; do not copy its facts.

Use `company/company.yaml` as the machine-readable source for skills. Do not put
secrets in it.
